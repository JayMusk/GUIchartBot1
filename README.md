# GUIchartBot - Cybersecurity Chatbot

A Windows Forms chatbot that helps users learn cybersecurity, manage tasks, take a quiz, and view activity logs.

Built in C# / .NET / Windows Forms.

## What it does

1.  **Chat Tab** - Chat with the bot. Ask about passwords, phishing, 2FA, scams, etc.
2.  **Task Assistant Tab** - Add, view, and complete cybersecurity tasks. Add a reminder with a title, description, and date.
3.  **Quiz Tab** - Answer 12 cybersecurity questions. Your score is shown as you go.
4.  **Activity Log Tab** - Shows everything you did in the app - tasks added, quiz answers, etc.

## How to run

1.  Open `GUIchartBot.sln` in Visual Studio
2.  Press `Ctrl + Shift + B` to Build
3.  Press `F5` to Run

If you get build errors, see "Common Errors" below.

## How to use the chatbot

In the Chat tab, type:

*   `hello` / `hi` - Bot greets you
*   `how are you` - Bot replies
*   `what is phishing` - Bot explains phishing
*   `add task - enable 2fa` - Adds a task called "enable 2fa"
*   `add task - update password` - Adds a task called "update password"
*   `show tasks` - Lists your tasks
*   `complete task 1` - Marks task 1 as done
*   `start quiz` - Starts the quiz
*   `help` - Shows all commands
